# 交付物一B轨：Figma 原型生成指令

## 统一设计规范

- **配色**：侧边栏 #1a1a2e / 主背景 #f8f9fa / 强调色 #4f46e5 / 成功色 #22c55e / 警告色 #f59e0b / 错误色 #ef4444
- **字体**：Inter / Noto Sans SC，正文 14px / 标题 20px / 小字 12px
- **图标**：Lucide 线性风格，2px 描边，20px
- **间距**：基础 8px，圆角：卡片 8px / 按钮 6px
- **整体风格参照 Notion/Linear，不要渐变、毛玻璃**

---

## 页面1：工作流画布页

### 布局
- 整体结构：左侧 240px 固定侧边栏 + 顶部 56px 导航栏 + 左侧 220px 节点库面板 + 中央画布区 + 右侧 360px 配置面板（可收起）
- 区域划分：侧边栏 15% | 节点库 14% | 画布 55% | 配置面板 23%（当面板关闭时画布占78%）

### 组件清单
| 组件 | 类型 | 位置 | 交互行为 |
|------|------|------|---------|
| 侧边栏导航 | Nav | 左侧 240px | 点击切换页面，当前页高亮 |
| 顶部工具栏 | Toolbar | 画布区顶部 | 按钮：文字模拟、真实通话模拟、保存、发布 |
| 语言切换 | Button | 顶部右侧 | 点击切换中英文 |
| 节点库面板 | Panel | 画布左侧 220px | 分区展示6类节点，可拖拽 |
| 节点卡片 | Card | 节点库内 | 拖拽到画布添加节点 |
| 画布 | Canvas | 中央区域 | 拖拽节点、连线、缩放平移 |
| 流程节点 | Card | 画布上 | 拖拽移动、双击配置、端口连线 |
| 连线 | SVG Path | 画布上 | 从输出端口拖到输入端口创建连线 |
| 配置面板 | Slide Panel | 右侧 360px | 双击节点打开，显示配置表单 |
| 缩放控件 | Button Group | 画布右下角 | 放大/缩小/适应 |
| 空状态 | Empty State | 画布中央 | 无节点时显示引导文案 |
| 校验提示 | Toast | 顶部右侧 | 环路/断路/必填项错误 |

### 交互状态
- **空状态**：画布中央显示"从左侧拖拽节点开始构建"+ 引导文案
- **编辑中**：节点蓝色选中框，配置面板滑出，保存按钮激活
- **校验失败**：Toast 红色提示，断路节点红色边框，必填项黄色标记
